## 5️⃣ Estrutura de Categorização

### Q5.1: Tags Fiscais Propostas

Propomos criar 4 tipos de tags fiscais automáticas:

**IRC:**
- `IRC_DEDUTIVEL_100` - Totalmente dedutível
- `IRC_DEDUTIVEL_PARCIAL` - Parcialmente dedutível
- `IRC_NAO_DEDUTIVEL` - Não dedutível
- `IRC_INVESTIMENTO` - Investimento (amortizável)

**IVA:**
- `IVA_DEDUTIVEL_100` - IVA totalmente dedutível
- `IVA_NAO_DEDUTIVEL` - IVA não dedutível
- `IVA_MISTO` - Uso misto (pro-rata)

**IRS:**
- `IRS_ISENTO` - Isento de retenção
- `IRS_RETENCAO_TRABALHO` - Trabalho dependente (tabela AT)
- `IRS_RETENCAO_25` - Trabalho independente (25%)
- `IRS_RETENCAO_11_5` - Certos serviços (11,5%)

**TSU:**
- `TSU_GERENTE` - Gerente (21,4% + 9,3%)
- `TSU_TRABALHADOR` - Trabalhador (23,75% + 11%)
- `TSU_ISENTO` - Isento TSU

**Questão:** Esta estrutura faz sentido? Falta alguma categoria importante?
